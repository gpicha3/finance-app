# Finance — บันทึกทางเทคนิค

ใช้ตอนกลับมาทำต่อ จะได้ไม่ต้องไล่โค้ดใหม่

## ภาพรวม

```
iPhone (PWA)  ⇄  Google Apps Script (Web App + TOKEN)  ⇄  Google Sheet "Finance"
```

- **แอป:** HTML/CSS/JS ล้วน ไม่มี build step — `index.html`, `styles.css`, `calc.js`, `app.js`, `theme.js`, `sw.js`
  - `calc.js` คือการคำนวณล้วน ๆ (รอบ, งบ, การผ่อน) ไม่แตะหน้าจอ มีเทสต์ที่ `tests/calc.test.js`
  - `app.js` คือหน้าจอ, การเชื่อมต่อ, gesture
- **Backend:** `apps-script/Code.gs` (อยู่ใน `.gitignore` เพราะมี TOKEN และยอดผ่อน — ห้าม push) ไฟล์นี้มีอยู่ในเครื่องนี้เท่านั้น
- **v1 ดูอย่างเดียว:** ไม่มีฟอร์มเพิ่ม/แก้/ลบ และไม่มี `doPost`
- **โฮสต์:** ยังไม่ได้สร้าง repo หรือ deploy (รอเจ้าของสั่ง)

## ชีตใน Sheet

| แท็บ | คอลัมน์ที่อ่าน | หมายเหตุ |
|---|---|---|
| Fix cost | A Month · B Topic · C Cost · D Total · G Income · H Balance | อ่านอย่างเดียว · A เป็นวันที่ merge ทั้งบล็อก จึงมีค่าแค่แถวบนสุด · ช่อง C ว่าง = `null` = แสดง "ยังไม่ระบุ" · รายการเก่าและใหม่ชื่อไม่เหมือนกัน แอปแสดงตามชื่อในชีต ไม่ได้ผูกกับชื่อรายการ |
| Daily Log | A วันที่ · B รอบเงินเดือน · C ประเภท · D หมวด · E รายการ · F จำนวน · G หมายเหตุ | อ่านอย่างเดียว เฉพาะ A–G · กล่องสรุปด้านขวา (I:J) ไม่ถูกแตะ |
| Installments | A name · B monthly · C totalMonths · D firstMonth · E dueDay | Apps Script สร้างและใส่ข้อมูลตั้งต้นครั้งเดียวเมื่อยังไม่มีแท็บ · D เป็นข้อความ `YYYY-MM` · แก้ไขในชีตได้เลย |

ถ้าหัวตาราง Fix cost หรือ Daily Log เปลี่ยน สคริปต์จะคืน error แทนการอ่านผิดคอลัมน์

ต้องอ่านด้วยค่าดิบจาก `getValues()` ห้ามใช้ `getDisplayValues()` เพราะบางช่องแสดงปัดเศษ (เช่น ค่าจริงมีทศนิยมแต่แสดงเป็นจำนวนเต็ม)

## กติการอบ

คีย์รอบ `YYYY-MM` = เดือน X

| อย่าง | ช่วง |
|---|---|
| บล็อก Fix cost เดือน X | 25 X – 24 ของเดือนถัดไป |
| รอบงบ Daily Log ของเดือน X | 26 X – 24 ของเดือนถัดไป |

- **วันที่ 25:** ไม่อยู่ในช่วงงบของรอบไหน หน้าแรกนับเป็นรอบใหม่แล้ว (เจ้าของตัดสินใจ) นับวันถึงเงินเดือนครั้งถัดไป
- **จัดกลุ่ม Daily Log ตามคอลัมน์รอบเงินเดือน** ไม่ใช่วันที่ คอลัมน์นี้ไม่มีปี จึงใช้คอลัมน์วันที่เลือกปีที่ทำให้วันเริ่มรอบใกล้วันที่ของแถวที่สุด (เจ้าของตัดสินใจ) ถ้าอ่านข้อความรอบไม่ได้ แถวนั้นแยกอยู่ท้ายสุดในรอบชื่อเดียวกับข้อความนั้น
- **กล่องสรุปในชีตกรองตามวันที่ แต่แอปกรองตามคอลัมน์รอบ** ถ้าแถวใดเขียนสองคอลัมน์ไม่ตรงกัน ยอดจะต่างกัน
- **แถวที่อ่านยอดหรือประเภทไม่ได้** ไม่ถูกนับ และแอปแสดงจำนวนแถวเตือน
- **งบ** 6,400 ต่อรอบ เก็บเป็นค่าคงที่ `BUDGET` ใน `calc.js`

## การผ่อน

- งวดของเดือนไหนนับว่าจ่ายแล้วเมื่อ **เลย** dueDay ของเดือนนั้น (วันที่ 25 เองยังไม่นับ เริ่มนับวันที่ 26)
- ยอดเต็มไม่รวมเงินดาวน์ = monthly × totalMonths · เดือนที่ผ่อนหมด = firstMonth + totalMonths − 1
- ยอดรวมต่อเดือน "ตอนนี้" นับเฉพาะรายการที่ตัดงวดแรกไปแล้วและยังไม่หมด รายการที่ยังไม่เริ่มแสดงเป็นบรรทัดบอก และเป็นยอดบวกในไทม์ไลน์

## Apps Script actions

- `GET ?k=TOKEN` → `{ fixCost: [...], daily: [...], installments: [...] }`
- TOKEN ผิด → `{ error: 'unauthorized' }` · อ่านไม่สำเร็จ → `{ error: 'ข้อความ' }`

## ติดตั้ง / อัปเดต Apps Script

ครั้งแรก:

1. เปิดชีต Finance → Extensions → Apps Script → วาง `apps-script/Code.gs` → Save
2. เลือกฟังก์ชัน `testRead` → Run → อนุญาตสิทธิ์ → ดูผลใน Execution log (ขั้นนี้จะสร้างแท็บ Installments)
3. Deploy → New deployment → Web app → Execute as: **Me**, Who has access: **Anyone** → Deploy → คัดลอก URL
4. Setup code = `URL?k=TOKEN` (TOKEN อยู่บรรทัดบนของ `Code.gs`) → วางในแอปที่ ตั้งค่า → Google Sheet

อัปเดต: วางโค้ดทับ → Save → Deploy → Manage deployments → ✏️ → New version → Deploy
(ห้ามกด New deployment เพราะ URL จะเปลี่ยน)

สถานะ: ติดตั้งและ Deploy ในชีตจริงแล้วเมื่อ 6 พ.ย. 2026

ถ้าคัดลอกโค้ดด้วย `pbcopy` จาก shell ต้องตั้ง `LC_ALL=en_US.UTF-8` ก่อน ไม่อย่างนั้นภาษาไทยที่วางในหน้าเว็บจะเพี้ยน
ถึงแม้ `pbpaste` จะอ่านกลับมาได้เท่าเดิม ให้ดูจากหน้า editor ว่าภาษาไทยอ่านออกก่อนกด Run ทุกครั้ง
เพราะข้อมูลตั้งต้นของ Installments จะถูกเขียนลงชีตตอนรันครั้งแรก

## Deploy แอป

- ยังไม่ได้ทำ ถ้าใช้ GitHub Pages แบบ fuel-logger: repo ใต้บัญชี gpicha3, push ผ่าน SSH alias `github.com-personal`, ใช้ `gh` ผ่าน `GH_TOKEN=$(gh auth token --user gpicha3)` (อย่าใช้ `gh auth switch`)
- **ทุกครั้งที่แก้ไฟล์แอป ให้เพิ่มเลขเวอร์ชัน `CACHE` ใน `sw.js`** ไม่อย่างนั้น iPhone อาจยังใช้ไฟล์เก่า
- ตกลงกันไว้: แก้เสร็จให้ commit ในเครื่องก่อน และสร้าง repo / deploy เมื่อเจ้าของสั่งเท่านั้น
- ห้าม commit ข้อมูลการเงินจริง: ข้อมูลตัวอย่างในแอปและเทสต์เป็นตัวเลขสมมติ

## ทดสอบในเครื่อง

```bash
node --test tests/calc.test.js
python3 -m http.server 5175 --bind 0.0.0.0 -d "<โฟลเดอร์ finance-app>"
```

- Mac: http://localhost:5175 · iPhone (Wi-Fi เดียวกัน): http://<IP ของ Mac>:5175
- ยังไม่วาง Setup code = แสดงข้อมูลตัวอย่าง (มีแถบบอกที่หน้าแรก)
- `?today=YYYY-MM-DD` ท้าย URL ใช้ดูหน้าจอของวันอื่น เช่นวันที่ 25 หรือวันที่บางรายการผ่อนหมด
- เป็น http จึงใช้ service worker ไม่ได้
- เรื่องแถบสถานะ/ความสูงจอ ต้องทดสอบจากแอปที่ Add to Home Screen เท่านั้น

## เรื่องที่รับมาจาก fuel-logger (iOS)

- **แถบสถานะ:** `theme.js` ตั้ง `apple-mobile-web-app-status-bar-style` ตามโหมด iOS อ่านค่าตอนเปิดแอปเท่านั้น
- **แถบว่างด้านล่าง:** ใช้ `100lvh` กับ `.shell` และ `.sheet`
- **ไอคอนแอป:** iOS จำไว้ตอนติดตั้ง ถ้าเปลี่ยนต้องลบแอปแล้ว Add to Home Screen ใหม่ (ต้องวาง Setup code ใหม่)
- **ข้อมูลในเครื่อง:** แอปบนหน้าจอโฮมเก็บข้อมูลแยกจาก Safari
- **ช่องกรอกต้องใช้ฟอนต์ ≥ 16px** ไม่อย่างนั้น iOS ซูมเองตอนแตะ
- คีย์ใน localStorage ใช้ `fa.*` (fuel-logger ใช้ `fl.*`)
